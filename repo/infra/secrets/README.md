# Operator-mounted secrets

This directory is mounted read-only into the `api` container at `/run/secrets`.
It must contain the following files before the stack is started:

- `kek` — 32-byte Key Encryption Key (operator-provisioned; never stored in git or the DB)
- `session_signing_key` — 32-byte HMAC signing key for session tokens

For the test stack these are generated by `scripts/generate_dev_secrets.sh`.
The production values must come from the operator's provisioning process.
